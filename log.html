로그 치환 실험실

한쪽으로 치우친 데이터를 ln(x)로 펴고, 그래도 치우치면 ln(ln(x))로 한 번 더 펴는 과정을 단계별로 봅니다. 단추를 누를 때마다 그래프가 움직입니다.

히스토그램 · 분포 모양
Q-Q 그래프 · 직선이면 정규
치우친 상태 막대 대칭에 가까운 막대 · 정규곡선 평균(점선) · 중앙값(실선) 값이 0보다 작은 불가능 구간

언제 로그 치환을 하나요?

이럴 때 씁니다

  • 막대그래프가 오른쪽으로 꼬리가 길게 늘어질 때
  • 평균이 중앙값보다 훨씬 클 때 (몇몇 큰 값이 평균을 끌어올림)
  • 값이 모두 0보다 크고, 작은 값과 큰 값이 수십 배 이상 차이 날 때
  • "얼마 올랐나"보다 "몇 % 올랐나"가 중요할 때
  • 큰 값일수록 들쭉날쭉(오차)도 커질 때
  • 양(+)의 왜도, 경험적으로 왜도 > 1 (0.5~1은 검토)1
  • 평균 ≫ 중앙값, Q-Q plot이 아래로 볼록
  • 엄격히 양수이며 max/min 비가 크다(한두 자릿수 이상)
  • 곱셈적(multiplicative) 생성과정, 탄력성·% 변화 해석이 필요 (헤도닉 가격모형의 ln P)
  • 분산이 평균에 비례하는 이분산(잔차 깔때기 모양) 완화

이럴 땐 쓰지 않거나 다른 방법

  • 0이나 마이너스 값이 있으면 그대로 못 씀 → ln(x+1) 등
  • 이미 좌우가 비슷하면 할 필요 없음
  • 왼쪽으로 치우치면 로그는 오히려 더 나빠짐 → 제곱 또는 반사 후 로그
  • 0~1 사이 비율(공실률 등)은 다른 방법을 씀
  • 0·음수 포함: ln(x+1), Yeo-Johnson, IHS(asinh) 검토
  • 이미 대칭이거나 음(−)의 왜도: 로그는 좌측 꼬리를 악화
  • 비율·확률(0~1): logit 변환
  • 최적 강도를 데이터로 정하려면 Box-Cox λ 추정 (λ=0이 로그)

한 번 더 로그(이중 치환) 할 때 주의

로그를 한 번 씌웠는데도 오른쪽 꼬리가 남으면 한 번 더 씌울 수 있어요. 하지만 ① 값이 1보다 커야 해요(ln(1)=0이라 두 번째 로그가 안 됨). ② 결과를 "몇 % 올랐다"처럼 쉽게 말하기 어려워져요. 그래서 실제로는 자주 쓰지 않고, 먼저 극단값 확인이나 다른 변환을 같이 살펴봐요.

ln(ln x)는 반복 로그(iterated log)로, 정의역이 x>1(밑 e 기준)입니다. 회귀계수의 % 해석이 사라지므로 보고용 모형에는 드물게 씁니다. 대안으로 Box-Cox λ(0보다 작은 λ는 로그보다 강한 변환), 극단값 원인 점검(오류·용도 혼재 → 층화), 로버스트·분위회귀를 함께 검토하세요. 또 계량경제학의 "이중로그모형(log-log model)"은 종속·독립변수 양변에 각각 로그를 취한 탄력성 모형을 뜻하며, 같은 변수에 로그를 두 번 씌우는 것과 다릅니다.

Python

import numpy as np, pandas as pd
from scipy import stats
import matplotlib.pyplot as plt

df = pd.read_csv("apt.csv")           # 매매가 열
x = df["매매가"]
lx = np.log(x)                         # 1차 로그
print("왜도 원자료:", stats.skew(x))
print("왜도 ln   :", stats.skew(lx))
if stats.skew(lx) > 0.5 and (x > 1).all():
    llx = np.log(lx)                   # 2차 로그
    print("왜도 lnln :", stats.skew(llx))

fig, ax = plt.subplots(1, 2, figsize=(9, 4))
ax[0].hist(lx, bins=30)
stats.probplot(lx, dist="norm", plot=ax[1])  # Q-Q
plt.show()
각주 · Notes
  1. 왜도 기준(|왜도| < 0.5 대칭, 0.5~1 중간, > 1 심함)은 교재마다 조금씩 다른 경험칙입니다. 표본 크기와 Q-Q 그래프, 정규성 검정을 함께 보세요.
  2. 재생기의 아파트 400건, 필지 500건은 수업용 모의 데이터입니다(고정 난수로 생성, 실제 통계 아님). 아파트는 로그정규, 필지 면적은 ln(ln x)가 정규, 분양률(300곳)은 ln(K−x)가 정규가 되도록 만들었습니다.
  3. ln(밑 e)과 log10은 상수배 차이일 뿐이라 분포 모양을 펴는 효과는 같습니다. 회귀의 % 해석은 ln이 편리합니다.
  4. 치환 후 분석 결과를 원래 단위로 되돌릴 때는 exp()를 쓰며, 평균을 되돌릴 때는 기하평균(중앙값에 가까움)이 된다는 점에 주의하세요.
